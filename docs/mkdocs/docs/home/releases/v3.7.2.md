# v3.7.2

Released on 2019-11-10.

Fixes a stack overflow for deeply nested input by making the destructor iterative; parsing of JSON
text is now bounded only by available memory (the binary-format parsers still recurse). All changes are backward-compatible.
[Full release notes](https://github.com/nlohmann/json/releases/tag/v3.7.2).
